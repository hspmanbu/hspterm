# Windows 11 前两阶段实机复测

这是待执行清单，不代表已在 Windows 11 实测。仅使用可丢弃测试主机/文件。第三阶段内存、CPU及缓存基准对照仍暂停。

1. 本地编辑：自动空闲关闭、手动关闭、关闭全部后队列移除；上传途中关闭安全等待，未同步草稿保留，不影响后续新编辑。
2. 历史：停用记录后仍能管理旧命令；两个主机的同名命令只删除选定主机；切走设置分类后正文清空；旧同步数据不恢复已删除命令；候选删除按钮悬停/聚焦才显示。
3. 弹窗：将窗口拖至屏外一半，在不同缩放的两块显示器分别打开确认框，正文可滚动且按钮可达；普通成功只显示状态，警告/错误保留可关闭提示。
4. 传输：上传/下载大文件并校验散列；限速、暂停继续、断线恢复不丢数据；显示速度按约3秒窗口更新。
5. 下载完成：普通文件可打开/定位，文件夹可直接打开目录；移除本地文件后提示真实错误，不能误开程序目录。
6. Explorer：从SFTP直接按住拖出到Explorer（不按Alt），首次手势完成文件、多文件及目录下载；窗口内拖放仍可用；取消手势/关闭源标签不错误复用其他会话。
7. 图片：复制截图后用“粘贴图片”菜单或设置的组合键，上传当前会话安全临时目录，终端仅插入绝对路径不回车；普通文字粘贴不受影响；上传期间切焦点/重连不会输入到别的会话。
8. 编辑进度：下载和上传均显示百分比、进度条及KiB/MiB；零字节/未知大小无除零、虚假百分比或溢出。
9. 资源栏：按主机开启后重连恢复；后台标签/失焦应用不持续采样；不会自动授予进程管理权限；底栏内容不重叠。
10. 面包屑：导航失败后重新编辑显示最后成功目录；右侧留白可点入编辑；深目录可横向滚动，片段导航与缓存补全可用。

已执行的Ubuntu/Windows CI检查及构建结果见同目录README.md和PROGRESS.md。Windows Server CI不等同于上述Windows 11真实桌面交互。
